# 端到端任务评测结果

## 运行概况

- 评测集：`backend/app/eval/task_set.json`
- 任务规模：100 条
- 评测方式：完整 LangGraph StateGraph 端到端执行，依据最终结构化状态判定，不使用 LLM-as-judge
- 运行范围：商品推荐、需求澄清、模拟下单、取消、订单明细查询、消费统计、订单查询澄清及其他请求
- 运行模式：单轮、串行执行；订单相关任务使用隔离评测数据并写入评测数据库，任务结束后清理夹具数据
- 结果：94/100 通过，端到端任务完成率 94%

## 评测限制与解释

1. 本结果来自单次单轮运行，不能单独证明多次重复运行下的稳定完成率。
2. 任务按串行方式执行，但本轮没有在评测脚本中显式增加官方商品 MCP 的 5 次/秒限速器；未观察到明确的 429 证据，因此不能把失败归因于 QPS 限制，也不能把本轮结果称为限流条件下的稳定基线。
3. 评测进程因存在失败任务返回退出码 1；该退出码表示评测发现失败样本，不表示评测未完成。
4. 若将 94% 作为长期稳定指标，建议加入统一限速、重复运行（例如 3 轮）并记录均值、最低值及波动范围。
